# Day 12: Cloud Monitoring, Logging & Cost Optimization

## 1. Cloud Monitoring

Cloud monitoring is the practice of tracking, analyzing, and managing cloud-based resources and services to ensure performance, availability, and reliability.

### Infrastructure Monitoring

- CPU utilization
- Memory usage
- Disk I/O and storage capacity

### Application Monitoring

- Application performance (response times, error rates)
- User experience metrics
- Service dependencies

### Network Monitoring

- Bandwidth usage
- Latency and packet loss
- Connectivity issues

### Performance Metrics

- Throughput
- Availability (uptime)
- SLA compliance

## 2. Cloud Logging

Logs are records of events generated by applications, systems, and services. They help in troubleshooting, auditing, and security analysis.

### Types of Logs

- Application logs (errors, requests, transactions)
- System logs (OS events, kernel messages)
- Security logs (authentication attempts, firewall activity)
- Audit logs (user actions, configuration changes)

### Importance of Centralized Logging

- Easier troubleshooting across distributed systems
- Enhanced security monitoring
- Compliance and audit readiness
- Single source of truth for operational data

## 3. Alerts and Notifications

Alerts notify teams when thresholds or anomalies are detected.

### Threshold-based Alerts

- Triggered when metrics exceed defined limits (e.g., CPU > 80%)

### Email/SMS Notifications

- Automated messages to stakeholders for quick response

### Incident Response Basics

- Identify issue → Assess impact → Mitigate → Document resolution

## 4.  Cloud Cost Optimization

Optimizing cloud costs ensures efficient resource usage and prevents overspending.

### Pay-as-you-go Pricing

- Pay only for consumed resources

### Rightsizing Resources

- Match instance size to workload requirements

### Auto Scaling

- Dynamically adjust resources based on demand

### Reserved Instances vs On-Demand Instances

- Reserved: Lower cost, long-term commitment
- On-Demand: Flexible, higher cost

### Removing Unused Resources

- Delete idle VMs, unattached volumes, unused IPs

### Storage Lifecycle Policies

- Move data to cheaper storage tiers (e.g., archive)

## 5.  Monitoring Tools

Popular cloud-native monitoring solutions:

### AWS Cloud Watch

- Metrics, logs, alarms, dashboards

### Azure Monitor

- Application Insights, Log Analytics, alerts

### Google Cloud Monitoring

- Metrics explorer, uptime checks, dashboards
