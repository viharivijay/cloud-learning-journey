- Why Kubernetes is Needed
- Kubernetes Architecture

- Deployments
- Services
- Namespaces

## Key Takeaways
- Kubernetes automates container management.
- Pods are the smallest deployment units.
- Deployments help maintain application availability.
- Services expose applications to users.
- Kubernetes provides scalability, self-healing, and load balancing.
