# Day 17 – Cloud Learning Journey

## Topic
Continuous Integration & Continuous Deployment (CI/CD)

## Overview
Today I learned about CI/CD, one of the most important DevOps practices used in cloud computing. CI/CD automates the process of building, testing, and deploying applications, helping teams deliver software faster and with fewer errors.

## Topics Covered
- Introduction to CI/CD
- Continuous Integration (CI)
- Continuous Delivery vs Continuous Deployment
- CI/CD Pipeline Stages
- Source Control
- Build Process
- Automated Testing
- Deployment
- Monitoring
- GitHub Actions
- Jenkins
- Azure Pipelines
- AWS CodePipeline
- CI/CD Best Practices
- Advantages and Challenges

## Key Learnings
- CI integrates code changes frequently to detect issues early.
- CD automates software delivery and deployment.
- CI/CD improves development speed, reliability, and collaboration.
- GitHub Actions, Jenkins, Azure Pipelines, and AWS CodePipeline are widely used automation tools.
- Automated testing and monitoring are essential for successful deployments.

## Outcome
Completed Day 17 by understanding how CI/CD pipelines automate software development and deployment in cloud environments, preparing for DevOps and cloud engineering roles.
