# Day 18 – Infrastructure as Code (Terraform Basics)

## Overview
Today I explored Infrastructure as Code (IaC) using Terraform, a powerful tool that automates the provisioning and management of cloud infrastructure through configuration files.

- Benefits of automation

- Terraform workflow

- Variables and outputs
- Terraform state file

- Real-world cloud automation use cases

- Explored providers, resources, variables, outputs, and state management.
- Recognized the importance of automation, consistency, and version control in cloud environments.
