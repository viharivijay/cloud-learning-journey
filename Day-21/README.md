# Day 21 – Cloud Auto Scaling

##  Overview

Today I learned about Cloud Auto Scaling, a cloud computing technique that automatically increases or decreases computing resources based on application demand.

## Topics Covered

- What is Auto Scaling?
- Need and benefits of Auto Scaling
- Horizontal Scaling
- Vertical Scaling
- Minimum, Maximum & Desired Capacity
- Scaling Policies
- Target Tracking
- Step Scaling
- Scheduled Scaling
- Health Checks
- Auto Scaling with Load Balancers
- AWS EC2 Auto Scaling

## How Auto Scaling Works

Users
  ↓
Load Balancer
  ↓
Auto Scaling Group
  ↓
EC2 Instances
  ↓
Automatically Add/Remove Instances

##  Key Benefits

-  Improves application performance
-  Reduces unnecessary cloud costs
-  Handles traffic spikes
-  Automatically manages resources
- Improves availability and reliability

##  Key Takeaway

Auto Scaling helps cloud applications automatically adapt to changing workloads by adding or removing resources according to demand.
