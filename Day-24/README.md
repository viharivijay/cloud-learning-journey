## Key Concepts

### Right-Sizing

Selecting cloud resources based on actual workload requirements.

### Auto Scaling

Automatically increasing or decreasing resources according to demand.

### Cost Allocation

Tracking cloud spending by project, team, department, or application.

### Fin Ops

A financial management approach that helps organizations optimize cloud spending and create financial accountability.
