# Day 26 – Containerization with Docker

## Overview
Today I explored **Docker**, one of the most important tools in cloud computing and DevOps. Docker allows developers to package applications and their dependencies into lightweight, portable containers, ensuring consistent execution across different environments.

## Common Docker Commands

```bash
docker --version
docker info
docker pull ubuntu
docker images
docker run ubuntu
docker run -it ubuntu bash
docker ps
docker ps -a
docker stop <container_id>
docker rm <container_id>
docker rmi <image_id>
```

## Key Takeaway
Docker is a powerful containerization platform that simplifies application development, deployment, and scaling while improving portability and resource efficiency.
