# Cloud-Native Architecture & Microservices

##  Overview

Day 38 of my **50-Day Cloud Learning Journey** focused on **Cloud-Native Architecture and Microservices**.

Cloud-native architecture is an approach to designing applications specifically for cloud environments using **microservices, containers, automation, CI/CD, scalability, resilience, and Infrastructure as Code (IaC).**

##  Key Concepts

| Concept            | Description                              |
| ------------------ | ---------------------------------------- |
| Microservices      | Small, independently deployable services |
| Containers         | Packages applications with dependencies  |
| Kubernetes         | Orchestrates containerized applications  |
| API Gateway        | Entry point for client requests          |
| Service Discovery  | Helps services locate each other         |
| Event-Driven       | Services communicate through events      |
| Horizontal Scaling | Adds more application instances          |
| Elasticity         | Automatically adjusts resources          |
| CI/CD              | Automates build, test and deployment     |
| IaC                | Manages infrastructure using code        |

##  Key Takeaways

* Cloud-native applications are designed specifically for cloud environments.
* Microservices provide independent deployment and scaling.
* Containers provide portable and consistent environments.
* Kubernetes manages containerized workloads.
* API Gateways manage communication between clients and services.
* Event-driven architecture enables loosely coupled systems.
* Horizontal scaling improves application scalability.
* Resilience and fault tolerance help applications handle failures.
* CI/CD enables automated software delivery.
* IaC enables automated and repeatable infrastructure management.
