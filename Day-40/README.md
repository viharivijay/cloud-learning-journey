# Cloud Governance and Compliance

##  Overview

Day 40 focuses on **Cloud Governance and Compliance**, which are essential for managing cloud environments securely, efficiently, and according to organizational and regulatory requirements.

Cloud governance defines policies and controls for cloud usage, while compliance ensures that applicable laws, standards, contracts, and internal policies are followed.

##  Governance vs Compliance

| Governance | Compliance |
|---|---|
| Defines rules and policies | Ensures requirements are followed |
| Manages cloud usage | Verifies adherence |
| Focuses on control | Focuses on meeting obligations |
| Helps prevent risks | Helps demonstrate compliance |

##  Practical Task

Create a basic cloud governance checklist:

- Enable MFA
- Follow least privilege
- Enable encryption
- Restrict public access
- Create a cloud budget
- Tag cloud resources
- Define naming conventions
- Enable audit logging
- Restrict unauthorized regions
- Review permissions regularly

---

##  Key Takeaway

> **Cloud Governance defines the rules for managing cloud resources, while Cloud Compliance ensures that required rules, regulations, and standards are being followed.**
