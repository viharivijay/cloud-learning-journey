# ☁️ 50-Day Cloud Computing Learning Journey 🚀

**Welcome to my 50-Day Cloud Computing Learning Journey!**

This repository documents my **50 days of structured cloud learning, hands-on practice, architecture concepts, and practical projects**.

The journey started with cloud computing fundamentals and progressed toward **cloud architecture, Kubernetes, cloud-native systems, migration, observability, FinOps, disaster recovery, and production-ready cloud solutions**.

#  Observability

Production cloud systems require visibility into their behavior.

### Three Pillars of Observability

**Metrics** → What is happening?

**Logs** → What happened?

**Traces** → Where did it happen?

These concepts help identify performance issues, failures, and application bottlenecks.
